# Example briefs

Each file here is a complete `BRIEF.yaml` from a real unattended run (outcomes in the top-level README under "Track record"). Copy one to your project root as `BRIEF.yaml`, edit the goal, deliverables and criteria, commit it, and run `bash scripts/run.sh`. All three parse with both brief readers; check any edit with `python3 scripts/brief.py validate --brief <file>` (it writes `.claude/state/brief.json`, so delete that file afterwards if no run is active). `readme-mission.yaml` is the first mission quickship ran on itself; `glossary-mission.yaml` is a small single-file mission with tight budgets; `localrag-mission.yaml` built a working CPU-only RAG CLI in 72 minutes, with the machine, stack and observed result in `localrag-notes.md`, which the brief points the lead at as `docs/BRIEF_NOTES.md`.
